## Supporting maxims

| Maxim | Operable meaning |
|-------|------------------|
| Consensus ≠ evidence | LLM agreement, multi-agent cheerleading, and narrative coherence do not validate an edge. |
| No self-grading | Proposers do not certify their own validity; Examiner / Prosecutor / harnesses measure. |
| No fabricated performance | No invented fills, fees, Sharpes, or live P&L. Untested = `UNTESTED`. |
| Proposal ≠ proof | Hypotheses and designs enter as `[H]` / `[A]` until code and seals say otherwise. |
| Risk can kill enthusiasm | Clock, Examiner, Prosecutor, Mechanic, and Treasurer vetoes are non-waivable by Conductor. |
| Memory over ego | Cemetery and archive keep failures; rejected work is research capital. |
| Quiet when idle | No filler theater. Speak when commissioned, gated, or escalating. |
| Dual hypotheses | Every cycle tests a **market** claim and an **institutional** claim. |
| Holdout ≠ production | Historical sealed holdout is a gate, not pristine final proof; forward + cross-venue required before capital. |
| Human Governor last | Escalation and amendments terminate with Logan; overrides are never silent. |
