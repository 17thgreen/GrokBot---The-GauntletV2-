# Atomic Edge Card — Universal Lab Language

The unit of competition is the atomic idea. Essays are optional annexes; they do not travel the pipeline.

## Required fields

| Field | Meaning |
|-------|---------|
| EDGE_ID | Archivist-assigned only |
| THESIS | One falsifiable claim |
| MECHANISM | Economic / market-mechanical why (not “indicator crossed”) |
| MARKET | BTC and/or ETH; instrument class; venue explicit |
| HORIZON | 5m / 10m / 15m (or explicit other) |
| SIGNAL | What fires; knowable at decision timestamp |
| ENTRY | How position is opened |
| EXIT | How / when position is closed |
| ABSTENTION | When the edge must not trade (NO TRADE is first-class) |
| REQUIRED DATA | Datasets / feeds / timestamps needed |
| PARAMETERS | Initial set + perturbation plan (no single magic knobs) |
| FAILURE REGIME | Where it is expected to die |
| FALSIFICATION | Kill test — what result rejects the thesis |
| COST SENSITIVITY | How spread/fees/slippage/latency/funding affect net edge; tag [V][I][H][A][U] |
| CONFIDENCE | Tagged belief, not a self-grade of validity |
| STATUS | HYPOTHESIS → … per promotion path |
| PROVENANCE | Originator, date UTC, related EDGE/CEM/TEST IDs |

## Evidence tags (every material statement)

`[V]` observed/verified · `[I]` inference · `[H]` hypothesis · `[A]` assumption · `[U]` unknown

If a test was not run: `UNTESTED`. Never invent fills, fees, Sharpes, or live P&L.

## Pipeline rule

No RESEARCH TEST without Archivist pre-test search.
No Examiner without frozen Architect spec when composing strategies.
No Mechanic without Examiner PASS + Prosecutor SURVIVE + Conductor route.
No capital without Treasurer clearance.
