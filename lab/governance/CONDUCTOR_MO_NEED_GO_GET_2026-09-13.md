# Conductor MO — Need → go get it
**Date:** 2026-09-13
**Stamp:** Logan (Human Governor), chat. Binding Conductor rule. Not an AMD (doctrine maxim filed the same day).

## Rule
When the lab needs something to further an experiment, strategy, or approach:

1. **Go get it**, or
2. **Delegate** the hunt to the seat that owns that surface (Clock for joins, Tape for venue tape, etc.).

Whichever is appropriate. Do **not** answer with a menu of alternatives instead of the attempt.

## When the hole is data — GitHub is on the path
Logan 2026-09-13 (after the Poly bid/ask hunt): scouring GitHub for missing tapes is a **validated, as-needed** step, not a standing Bot and not a weekend cron.

On every new DATA need, before calling the hole BLOCKED:
1. Probe the venue / official API (as now).
2. **Search GitHub** for dumps, parquet, SQLite, releases, and scrapers that point at a public archive (repos + code search). Click through to bytes, not READMEs.
3. If a scraper names an archive (PMXT, HF, R2), probe the **documented key** for the actual window. Wrong URL ≠ miss.
4. File the hunt (what was searched, HTTP, coverage vs the needed window). A dump for the wrong week is a miss.
5. Clock still owns the join. GitHub bytes are inventory, not READY, not a TEST.

Do **not** hire a Scout/Visionary Bot for this. Conductor or the owning seat does it when the hole appears. Intake Auditor wide-net (when hired) includes this; until then Conductor does not skip it.

## After the attempt
- Found: file it, Clock it, continue.
- Not published / 404 / empty: write the probe (endpoint, status). That **is** the result. Then the next leftover.
- Spend or a secret only Logan can give: ask once, with the probe already done.

## Still forbidden
Invented quotes or fills · treating last as mid · Examiner on an illegal incumbent · fourth READY without a written cycle waiver · L2 purchase without DATA spec + Treasurer/Governor · waiving Clock / Examiner / Treasurer.

## Why
A needed tape left as “we could do A or B” is idle theater. The kill rule already forbids sitting after a ruled-out approach. This forbids sitting behind a menu when the next physical step is acquire.
