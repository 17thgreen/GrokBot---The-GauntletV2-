**Date:** 2026-09-13  
**Stamp:** Logan (Human Governor), chat. Binding Conductor rule. Extends Need → go get it. Not an AMD. Not a hire.

## Rule
Whenever the lab has a **new data need**, GitHub is a valid and required hunt step — repos, releases, code search, and the public archives those repos point at. As-needed. Not a standing scrape. Not a new fleet member.

## Why
The 2026-09-13 Poly book hunt showed: official CLOB history can be empty while GitHub still holds a real BTC/ETH bid/ask dump (`gensx-x1/polymarket-btc-eth-updown-data`) and scrapers that name the correct PMXT parquet key. Skipping GitHub is how we almost called a tape dead after probing the wrong URL.

## How (minimum)
- Search GitHub for the object (bid/ask, 1s ticks, 1m coins, etc.) and the window.
- Distinguish **hosted bytes** from **scraper that points elsewhere**. Follow the pointer.
- Match the **needed window**. Aug dump ≠ Sep week.
- File the probe. Clock-clear before any Feature uses it.
- Paid / gated GitHub-adjacent vendors stay FORBIDDEN without a DATA spec + spend approval.
