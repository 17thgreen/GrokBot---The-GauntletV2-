# Alpha Lab Archive — The Archivist

Canonical permanent memory for the short-horizon BTC/ETH alpha lab.

**Path:** `/workspace/lab/archive`  
**Rule:** Nothing important disappears. Rejected strategies are proprietary research memory, not trash.

## Before any hypothesis enters testing

1. Search this archive (INDEX + cemetery + edges).
2. Report: duplicate / semantic equivalent / related / prior failure / clean.
3. Only then allow RESEARCH TEST intake.

## Layout

| Path | Contents |
|------|----------|
| `edges/` | Atomic Edge records (one idea, independently testable) |
| `strategies/` | Strategy versions & frozen specs |
| `tests/` | Test runs, datasets used, deterministic measurement refs |
| `cemetery/` | Rejected ideas with full failure taxonomy |
| `deployments/` | Shadow / paper / micro / limited / production + demotions |
| `datasets/` | Dataset registry (what was knowable when) |
| `red-team/` | Prosecutor objections linked to EDGE/STRATEGY IDs |
| `overrides/` | Human overrides (never silent) |
| `audit/` | Append-only intake / search / promotion / demotion log |
| `templates/` | Record templates |
| `INDEX.md` | Master searchable index |
| `SCHEMA.md` | Field schemas & ID conventions |
| `FAILURE_CLASSES.md` | Failure taxonomy |

## Evidence tags (mandatory on material statements)

`[V]` observed/verified · `[I]` inference · `[H]` hypothesis · `[A]` assumption · `[U]` unknown

## Promotion path (record stage, never waive gates)

HYPOTHESIS → RESEARCH TEST → VALIDATION → HISTORICAL SEALED HOLDOUT → CROSS-VENUE REPLICATION → FORWARD SHADOW → PAPER → MICRO CAPITAL → LIMITED CAPITAL → PRODUCTION

(See governance/CONSTITUTIONAL_AMENDMENT_FORWARD_AND_CROSS_VENUE.md — historical holdout ≠ production proof.)

## Demotion path

PRODUCTION → LIMITED → PAPER → SHADOW → RETIRED

## Intake

Agents file records via Archivist using templates. Archivist assigns IDs, indexes, and runs pre-test duplicate search.
